# 미분 공식 정리 노트

## 1. 미분계수와 도함수
함수 f(x)의 x = a에서의 미분계수는 평균변화율의 극한으로 정의한다.
f'(a) = lim(h→0) [f(a+h) − f(a)] / h
이 값은 곡선 y = f(x) 위의 점 (a, f(a))에서 그은 접선의 기울기와 같다.
모든 x에 대해 미분계수를 대응시킨 함수 f'(x)를 도함수라고 하고, 도함수를 구하는 과정을 미분한다고 말한다.
미분가능한 함수는 반드시 연속이지만, 연속이라고 해서 항상 미분가능한 것은 아니다. 예를 들어 f(x) = |x|는 x = 0에서 연속이지만 뾰족점이 있어 미분가능하지 않다.

## 2. 기본 공식
- 상수함수: (c)' = 0
- 거듭제곱 법칙: (xⁿ)' = n·xⁿ⁻¹ (n은 실수)
- 상수배: (c·f)' = c·f'
- 합과 차: (f ± g)' = f' ± g'
예) f(x) = 3x⁴ − 2x² + 5x − 7 이면 f'(x) = 12x³ − 4x + 5

## 3. 곱의 미분법
(f·g)' = f'·g + f·g'
두 함수가 동시에 변할 때, 한쪽만 조금 변한 효과를 각각 더한 것으로 이해할 수 있다. 가로 f, 세로 g인 직사각형의 넓이 변화를 떠올리면 기억하기 쉽다.
예) (x²·(x+1))' = 2x·(x+1) + x²·1 = 3x² + 2x

## 4. 몫의 미분법
(f/g)' = (f'·g − f·g') / g²   (단, g ≠ 0)
분자의 순서(f'g − fg')를 바꾸면 부호가 틀리므로 주의한다.
예) (1/x)' = (0·x − 1·1)/x² = −1/x²

## 5. 합성함수의 미분법 (연쇄법칙)
y = f(g(x))이면 y' = f'(g(x))·g'(x)
바깥 함수를 먼저 미분하고(안쪽은 그대로 둔 채), 안쪽 함수의 도함수를 곱한다.
dy/dx = (dy/du)·(du/dx) 처럼 분수를 약분하는 모양으로 기억하면 편하다.
예) ((2x+1)⁵)' = 5(2x+1)⁴·2 = 10(2x+1)⁴

## 6. 자주 하는 실수
1. 곱의 미분을 (fg)' = f'g' 로 계산하는 실수
2. 연쇄법칙에서 안쪽 함수의 도함수를 곱하지 않는 실수
3. 몫의 미분에서 분모를 제곱하지 않는 실수

## 7. 활용
- 접선의 방정식: y − f(a) = f'(a)(x − a)
- 증가·감소: f'(x) > 0 이면 증가, f'(x) < 0 이면 감소
- 극값: f'(x) = 0 이 되는 점의 좌우에서 부호가 바뀌는지 확인한다.
- 속도와 가속도: 위치 x(t)를 미분하면 속도 v(t), 속도를 미분하면 가속도 a(t)가 된다.
